# 页面 07 · 设备与设置

- **路由**：`/device` · 侧栏图标 Lucide `settings-2`
- **功能域**：设备信息、固件升级、插孔设置、自动切换、全局配置档、通用设置

## 布局

```
[ 设备与设置标题 ]
[ 顶部：设备信息卡（实物缩略图 + 版本 + 序列号，横向）        ]
[ 中部左：固件升级卡        ][ 中部右：插孔设置卡             ]
[ 自动切换 开关              ][ 全局配置档 列表               ]
[ 底部：通用设置（语言/主题/启动项/关于）                      ]
```

- 桌面：设备信息横跨整行，其余 2 列；<768px 单列。
- 本页信息密度略高于其他页（VISUAL_DENSITY=3，仍保持留白），用 `border-t` 分组而非卡片套卡片。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| 设备信息卡 | Card | 实物缩略图 + 「朱雀 CM002X1」+ 固件版本（等宽）+ 序列号（等宽，可复制） |
| 固件升级 | Card + Button | 图标 `download`；状态：已是最新（`--success`）/ 有更新（`--accent`）/ 升级中（进度条 + 诚实百分比） |
| 插孔设置 | Segmented + 说明 | 耳麦 / 耳机 / 麦克风输入切换；图标 `plug` |
| 自动切换 | Switch | 图标 `refresh-cw`；开启后插入设备自动切换配置档 |
| 全局配置档 | List + Radio | 每行 1 档：名称 + 场景标签 + 激活单选框（`--accent`） |
| 通用设置 | Form | 语言 `Select` / 主题 `Segmented`(浅色·深色·跟随系统) / 开机自启 `Switch` / 关于 |

## 交互与状态

- 固件升级：点击 → 二次确认（说明升级中勿断开）→ 进度条；**不显示假进度**，进度来自真实任务；失败显示 `--danger` + 「重试」。
- 序列号复制 → 成功后 Toast（`--success` 图标 + 文案），2s 自动消失。
- 主题切换即时生效，写入 `data-theme`。
- **状态覆盖**：Loading（读取设备信息 → 骨架）/ Empty（无设备 → 「未检测到设备」+ 去概览检测）/ Error（读取失败 → 重试）/ Populated / Edge（超长序列号省略号 + tooltip、配置档超 12 条虚拟滚动）。
- 强调色预算：主按钮 / 激活单选框 / 有更新标记三者合计可见 `--accent` ≤2 处。
