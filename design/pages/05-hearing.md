# 页面 05 · 助听（HyperHear）

- **路由**：`/hearing` · 侧栏图标 Lucide `ear`
- **功能域**：HyperHear 增强听力、听力补偿曲线、场景预设

## 布局

```
[ 助听标题 + 「开始校准」Primary 按钮（右） ]
[ 左：听力补偿曲线（约 55%）      ][ 右：配置面板 ]
[   频率增益折线（等宽刻度）       ][ 补偿强度 滑杆 ]
[                                ][ 场景 段控(4) ]
[                                ][ 左右耳独立 开关 ]
[ 底部：校准状态说明（诚实文案） ]
```

- 双列 6:5；<768px 单列。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| 补偿曲线 | SVG 折线 | 按频段（125Hz–8kHz）增益；网格 `--equ-grid`；曲线 `--accent-2`（正向） |
| 补偿强度 | Slider | 0–100% |
| 场景 | Segmented(4) | 通用 / 交谈 / 电视 / 户外 |
| 左右耳独立 | Switch | 开启后曲线分为左右两条 |
| 校准状态 | Inline Status | 未校准用 `--warn` 文案，已校准 `--success` |

## 交互与状态

- 点击「开始校准」→ 分步引导（每步一句、≤4 项选择），显示当前步骤进度。
- **状态覆盖**：Loading（校准计算中 → 骨架）/ Empty（未校准 → 引导文案 + CTA，**不显示假进度**）/ Error（校准中断 → 重试）/ Populated / Edge（补偿值越界钳制）。
- 文案诚实：不使用「100% 恢复听力」类夸大承诺；说明「根据你的试听反馈调整，不替代医学诊疗」。
- 强调色预算 ≤2：曲线走 `--accent-2`，`--accent` 仅「开始校准」主按钮一处。
