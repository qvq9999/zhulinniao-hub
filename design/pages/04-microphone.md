# 页面 04 · 麦克风

- **路由**：`/mic` · 侧栏图标 Lucide `mic`
- **功能域**：麦克风 EQ、降噪 / AI 降噪、魔音变声、录音音效

## 布局

```
[ 麦克风标题 + 实时电平表（右上） ]
[ 左：麦克风 EQ 曲线（约 50%） ][ 右：处理链（约 50%） ]
[   5 段 EQ + 预置           ][ 降噪 开关 / 强度 滑杆 ]
[                            ][ AI 降噪 开关（sparkles 图标）]
[                            ][ 魔音变声 Select(预设) ]
[                            ][ 录音音效 Segmented ]
[ 底部：实时监听 开关（耳机试听） ]
```

- 双列 1:1；<768px 单列。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| 实时电平表 | Meter | 竖向条，`--accent-2` 正常 / `--warn` 接近削波 / `--danger` 削波；等宽 dB 值 |
| 麦克风 EQ | SVG 折线 + 5 拖拽点 | 网格 `--equ-grid`，中轴 `--equ-mid` |
| 降噪 | Switch + Slider | 图标 `audio-waveform`；强度 0–100% |
| AI 降噪 | Switch | 图标 Lucide `sparkles`（**矢量图标，非 emoji**） |
| 魔音变声 | Select | 预设：原声/低沉/明亮/机器人/儿童；图标 `wand-2` |
| 录音音效 | Segmented(3) | 干声 / 直播 / 录音棚；图标 `mic-vocal` |
| 实时监听 | Switch | 图标 `headphones` |

## 交互与状态

- 电平表 60fps 刷新，纯 CSS transform 避免重排。
- AI 降噪与普通降噪互斥：开启 AI 时普通降噪自动置灰并提示「已由 AI 降噪接管」。
- **状态覆盖**：Loading（打开麦克风设备 → 骨架条）/ Empty（未检测到麦克风 → 引导检查系统权限）/ Error（权限被拒 → 明确错误 + 「打开系统设置」按钮）/ Populated / Edge（静音输入 → 电平表归零并显示「无输入」）。
- 强调色预算：电平表走 `--accent-2`，`--accent` 仅「实时监听」开启态一处。
