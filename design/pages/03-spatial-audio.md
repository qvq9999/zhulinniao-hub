# 页面 03 · 空间音频

- **路由**：`/spatial` · 侧栏图标 Lucide `move-3d`
- **功能域**：头动追踪、7.1 虚拟声场、虚拟扬声器布局

## 布局

```
[ 空间音频标题 + 头动追踪开关（右） ]
[ 左：虚拟扬声器俯视图（SVG，约 60%）  ][ 右：参数面板 ]
[ 7.1 扬声器点位环绕听者            ][ 声道模式 Segmented ]
[ 听者头像中心，可拖拽旋转           ][ 头动追踪 开关+灵敏度 ]
[                                    ][ 声场宽度 滑杆 ]
[                                    ][ 房间混响 段控 ]
```

- 双列 7:5；<768px 单列。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| 虚拟扬声器图 | SVG 俯视图 | 8 个扬声器用 Lucide `speaker` 24px 环绕；听者中心 `--fg`；激活声道 `--accent-2` |
| 声道模式 | Segmented(2) | 立体声 / 7.1 |
| 头动追踪 | Switch + Slider | 图标 `move-3d`；灵敏度 0–100% |
| 声场宽度 | Slider | 0–200% |
| 房间混响 | Segmented(3) | 关闭 / 客厅 / 剧院 |
| 方位指示 | Badge | 显示当前头部朝向如 `前置 -15°`（等宽） |

## 交互与状态

- 拖拽听者头像旋转 → 实时更新朝向角度与扬声器增益高亮。
- 头动追踪开启 → 顶部出现「校准」Secondary 按钮；未校准时显示 `--warn` 提示条。
- **状态覆盖**：Loading（探测陀螺仪 → 骨架）/ Empty（硬件不支持头动追踪 → 该组置灰 + 说明文案，非报错）/ Error（校准失败重试）/ Populated / Edge（角度越界回绕）。
- 强调色预算 ≤2；扬声器激活色固定 `--accent-2`，`--accent` 只留给当前选中项一处。
