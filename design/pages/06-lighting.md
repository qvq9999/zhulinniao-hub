# 页面 06 · 灯光（LED）

- **路由**：`/lighting` · 侧栏图标 Lucide `lightbulb`
- **功能域**：LED 开关、灯效模式、亮度 / 速度、颜色

## 布局

```
[ 灯光标题 + 全局 LED 开关（右） ]
[ 左：灯效预览（实物耳机 LED 高亮，约 55%） ][ 右：参数面板 ]
[   耳机轮廓图 + 发光点位示意             ][ 灯效模式 段控(4) ]
[                                        ][ 亮度 滑杆 ]
[                                        ][ 速度 滑杆（呼吸/流动时可用）]
[                                        ][ 颜色 色板（8 色预设 + 自定义）]
```

- 双列 6:5；<768px 单列。
- 灯效预览用实物图叠加发光图层（`box-shadow`/SVG 光晕），不使用毛玻璃。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| 灯效预览 | Image + Glow overlay | 耳机图上的发光点随所选颜色/亮度实时变化 |
| 全局 LED | Switch | 关闭后其余参数置灰 |
| 灯效模式 | Segmented(4) | 常亮 / 呼吸 / 流动 / 关 |
| 亮度 | Slider | 0–100%，图标 `sun` |
| 速度 | Slider | 0–100%，图标 `activity`（仅呼吸/流动可用） |
| 颜色 | Swatch grid | 8 色预设 + 自定义；色板圆点 28px，选中带 1px 描边环 + `--focus-ring` |

## 交互与状态

- 关闭全局 LED → 其余控件 `opacity: 0.45` 且 `aria-disabled`，附「LED 已关闭」提示。
- **状态覆盖**：Loading（读取灯效参数 → 骨架）/ Empty（设备不支持灯光 → 该页显示说明 + 返回概览）/ Error（写入失败 → 提示 + 重试）/ Populated / Edge（自定义颜色越界钳制）。
- 强调色预算：灯效预览是颜色主体（非 `--accent`）；`--accent` 仅「全局 LED 开关」开启态一处（若开关用 `--accent-2`，则 `--accent` 归零）。
- 注意：灯效颜色本身是用户 UGC 数据，允许任意色值；但 UI 控件描边/文字仍走 Token。
