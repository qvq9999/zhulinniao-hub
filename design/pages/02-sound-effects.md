# 页面 02 · 音效

- **路由**：`/sound` · 侧栏图标 Lucide `sliders-horizontal`
- **功能域**：EQ、动态低音、环绕、人声清晰度、智能音量、环境音效

## 布局

```
[ 音效标题 + 「重置」Ghost 按钮（右） ]
[ 主区左：EQ 曲线面板（约 60%）]   [ 右：参数面板（约 40%）        ]
[   SVG 10 段 EQ + 预置下拉       ][ 动态低音 滑杆                  ]
[   dB/Hz 坐标（等宽字体）        ][ 环绕声 开关 + 强度滑杆         ]
[                                 ][ 人声清晰度 滑杆               ]
[                                 ][ 智能音量 开关                 ]
[                                 ][ 环境音效 段控(4 预设)         ]
[ 底部：保存配置 / 恢复默认       ]
```

- 桌面双列 7:5；<768px 单列（EQ 在上，参数在下）。
- 每组参数 ≤4 项可见（工作记忆规则），超出用「高级」渐进披露。

## 核心组件

| 组件 | 控件类型 | 规格 |
|---|---|---|
| EQ 曲线 | SVG 折线 + 10 拖拽点 | 曲线 `--accent`；网格 `--equ-grid`；中轴 `--equ-mid`（虚线）；每点 8px 圆 + 悬停 12px |
| 频段数值 | 文本（等宽） | `JetBrains Mono` `--text-xs`，显示如 `+3.5 dB @ 1kHz` |
| 预置下拉 | Select | Lucide `chevron-down`；选项：平坦/低音增强/人声/古典/自定义 |
| 动态低音 | Slider | 0–100%，图标 `waves`；填充 `--accent-2` |
| 环绕声 | Switch + Slider | 开关轨道 40×24；开启态 `--accent`（品牌动作） |
| 人声清晰度 | Slider | 0–100%，图标 `audio-lines` |
| 智能音量 | Switch | 图标 `volume-2` |
| 环境音效 | Segmented(4) | 标准 / 观影 / 游戏 / 音乐，`--surface-2` 容器 |

## 交互与状态

- EQ 拖拽点：按住拖动改 dB（-12 ~ +12），实时重绘曲线；键盘 ←/→ 微调 0.5dB，Home/End 归零；释放时 `--motion-fast` 回弹。
- 每个滑杆拖动 → 数值实时刷新；`aria-valuenow` 同步。
- **状态覆盖**：Loading（读取设备参数 → 骨架脉冲）/ Empty（设备未连接 → 灰色面板 + 引导去检测）/ Error（写入失败 → 字段下方 `--danger` 文案 + 重试）/ Populated / Edge（数值越界钳制）。
- 强调色预算：EQ 曲线 + 环绕开关，**任选其一**走 `--accent`，另一走 `--accent-2`，全屏 `--accent` ≤2 处。
