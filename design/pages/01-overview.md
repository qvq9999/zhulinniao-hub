# 页面 01 · 概览（首屏）

- **路由**：`/`（默认首屏，侧栏第一项「概览」）
- **寄存器**：Product · **节区节奏**：桌面 48 / 平板 32 / 手机 24px
- **一句话目标**：让用户在 3 秒内确认耳机是否可调，并知道从哪下手。

## 布局

```
[左侧 Sidebar 220px] [顶部工具栏 56px                        ]
                     [ 概览标题 + 设备状态胶囊（右对齐）        ]
                     [ ────────────────────────────────────────]
                     [ 中央：设备实物热区图区（约 60% 宽，留白）]
                     [   左/右浮出热区引线卡片（2–4 张）         ]
                     [ 底部：快速入口 4 项（Grid，非卡片墙）    ]
```

- 采用 Grid：`grid-template-columns: 1fr minmax(320px, 520px) 1fr`，设备图居中，引线卡片左右分布（DESIGN_VARIANCE=4，属「偏移」级别，非对称但不混乱）。
- <768px 回退单列：设备图在上，引线卡片以纵向列表直接列点位。

## 核心组件

| 组件 | 控件类型 | 说明 |
|---|---|---|
| 设备状态胶囊 | Status Pill | `--surface-2` 底 + `--fg-2` 文字；连接成功图标 Lucide `circle-check`（`--success`） |
| 设备实物热区图 | Image + SVG overlay | 中央主角，见三态与热区方案 |
| 热区引线卡片 | Card + Leader line | 1px `--border`；悬停点位 `--hotspot-halo` 光晕 |
| 快速入口 | Icon Link ×4 | 音效 / 空间音频 / 麦克风 / 灯光，Lucide 24px |

## 交互与状态

- 悬停热区点位 → 点位光晕放大 + 对应引线加粗 + 卡片边框转 `--accent`（**此刻仅 1 处强调色**，不叠加）。
- 点击热区点位 → 进入对应设置页（EQ → 音效页；麦克风 → 麦克风页；头梁/耳罩 → 空间音频；Logo → 灯光）。
- 键盘：Tab 依次经过每个热区点位（点位为 `<button>`，配 `aria-label="音效设置"` 等）；`:focus-visible` 用 `--focus-ring`。

## 空/异常传播

概览不单独断网；设备状态由连接检测三态统一驱动（见 `03-connection-states.md`）。

## 反 AI 模板自检

- 禁止「大标题 + 副标题 + 居中 CTA + 抽象 3D 图形」Hero。首屏主角是**设备实物图**，不是口号。
- 禁止「10000+ 用户信赖」「99.9% 稳定」等虚构指标。
- 四大口干按钮不并排堆成卡片墙，用图标链接 + 留白分组。
