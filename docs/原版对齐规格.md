## 一、原版对 ZG3 的真实功能范围（真机截图 = 铁证）

原版 XearONE 主窗口（`orig-big.png`）在 ZG3 上只显示：

**耳机卡片（7 项）**：均衡器 / 7.1环绕 / 音频明亮化 / 动态低频 / 智能音量 / 人声清晰化 / 环绕扩增
**麦克风卡片（2 项）**：魔幻音效 / 麦克风降噪

另有：每卡片 音量 + 左右平衡 + 静音 + 「串联游戏设置」下拉；顶部 添加装置 / 信息。

**未显示 = 本设备 license 不含**（原版按 `CmLicenseCategory` 过滤）：
环境仿真音效、7.1 Virtual Speaker Shifter、音阶升降、原音消除、麦克风回音、麦克风均衡器、
麦克风录音特效（Compressor / LDR / Noise Gate）、AI 降噪、魔幻音效 II、警戒模式、
语音控制、Xear 超感听觉、Xear 3D全景空间音频（头部追踪）、LED、固件更新。

设备侧（Jokkoo）通道**在本硬件上不存在**：`hid_probe` 显示 ZG3 只暴露 2 个
**usage page 0x000C（消费者控制）** 接口，没有任何 vendor-defined 集合；
`ffi_probe` 中 `CmInit(0x0D8C)` 成功但 `CmGetDevice` 恒返回 0 台设备。
→ **LED / HyperHear / 警戒 / 头部追踪 / 语音控制 / 固件与电池 一律不可用**，不得假装生效。

## 二、9 项功能的精确规格（全部走注册表，已实测可读写）

注册表根：`HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\MMDevices\Audio\{Render|Capture}\{端点}\FxProperties\{上下文}\User`
写入权限 `KEY_READ|KEY_SET_VALUE`（免管理员）。

### ⚠️ 写入通道：必须走官方属性存储，裸写注册表不会实时生效（2026-10-17 实测）

- 裸写注册表只能把值**落盘**；音频引擎不收到通知，APO 只在流初始化时读一次 →
  表现为「拖了推子但听不出变化，要换歌/重开播放器才生效」。
- 正确通道：`IAudioSystemEffectsPropertyStore::OpenUserPropertyStore(STGM_READWRITE)`
  + `SetValue` + **`Commit()`** → 引擎收到变更并让 APO 重读，**即时生效**。
- 激活姿势（Microsoft «Windows 11 APIs for Audio Processing Objects»）：
  `InitPropVariantFromCLSID(上下文GUID, &pv)` → `IMMDevice::Activate(IID_IAudioSystemEffectsPropertyStore, CLSCTX_INPROC_SERVER, &pv)`
  —— **必须带这个 VT_CLSID 激活参数**，传空会得到 `E_INVALIDARG`（此前踩过的坑）。
- 本机实测：`OpenUserPropertyStore(READWRITE)` **免管理员即可成功**（文档说非管理员只读，实际 ACL 允许写）。
- 项目实现：`apo.rs` 的 `fx_store` 模块优先走这条通道，失败才回退裸写注册表；
  `cargo test --lib` 8 项真机往返测试覆盖。

上下文（CAPX）：
| 简称 | GUID | 用途 |
|---|---|---|
| MFX | `{4C6C316B-C24F-421C-A266-690540CABD11}` | EQ、K歌、麦克风回声/魔幻音效 |
| SFX | `{C31A35A5-22EC-425E-9B74-B64700F067DA}` | 明亮化/人声清晰化/动态低频 (INF 默认位) |
| EFX | `{9C97FB8F-7C45-4EF3-A5A8-67D0AC630E8F}` | 7.1环绕(CONLAB)、环绕扩增、VRMS |

> 实测：耳机端点(MFX/EFX 上下文)与麦克风端点(MFX/EFX 上下文)各自独立；
> 生效读取以 **MFX 优先、其次 EFX/根** 为原则（详见 `apo.rs` 现有实现）。

### 1. 均衡器（Label_Title_EQ）
- 开关：`Enable_EQ_GFX` = `{BD341FFB-9FD1-4ED4-8159-7999D546EA8A},0`
- 10 段增益：`EQ_Slider1..10` = pid **1..10**，**量程 -20…+20**（原版 `SetBand` 硬钳位 ±20）
- 10 段频率：`EQ_BandFreq1..10` = pid **11..20**，默认 `30,60,120,250,500,1000,2000,4000,8000,16000`
- 10 段 Q：`EQ_BandQ1..10` = pid **21..30**，默认 **14**（×100）
- 10 段滤波类型：`EQ_BandFilterType1..10` = pid **31..40**，取值 `0..5`

  > `EQViewModel`/`EQ2Preset.json` 那条新视图路径**在本产品里不会被走到**。

## 四、通道能力总结（决定"能不能调"）

| 通道 | 状态 | 覆盖功能 |
|---|---|---|
| 注册表 FxProperties | ✅ 已实测可读写 | 上述 9 项全部 |
| Core Audio（IAudioEndpointVolume） | ✅ | 音量 / 静音 / 平衡 |
| 厂商 DLL（Jokkoo / XearSDK / FW） | ⚠️ 可加载、Init 成功，但**枚举不到设备** | LED / HyperHear / 警戒 / 头部追踪 / 语音控制 / 固件 / 电池 → **不可用** |
| HID vendor 集合 | ❌ 硬件不存在 | 同上 |

**结论：ZG3 上"能正常调用"的功能 = 上述 9 项 + 音量/静音/平衡 + 装置信息读取。
其余任何功能都不能声称可用。**
