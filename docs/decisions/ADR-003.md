# ADR-003: 锁定 Lucide 作为全项目统一 SVG 图标库

## Status
Accepted (2026-10-16)

## Background
团队级 P0 规则：**禁止 emoji 作为功能图标**，Spec 必须锁定一套 SVG 图标库，前端依赖随之锁定，全项目统一不混用。

候选图标库（均具备 React 组件包与 SVG 源）：
- Lucide（lucide-react）
- Heroicons
- Tabler Icons
- Material Symbols

评估维度：图标覆盖度、线宽/风格一致性、包体积与 tree-shaking、React 支持、许可证、是否可离线内联。

## Decision
锁定 **Lucide**（`lucide-react`）为全项目唯一图标库。

理由：
- 覆盖音频/音量/耳机/滑块/开关/设置等本产品所需语义图标。
- 默认 24px、`stroke-width` 一致，风格统一，适合专业音频工具 UI。
- 单图标可 tree-shake，按需 import（`import { Volume2 } from 'lucide-react'`）。
- ISC 许可证，商用友好；SVG 可离线内联，满足桌面应用离线要求。

约束：
- 全项目仅允许 `lucide-react`，禁止混用其他图标库或 emoji。
- 图标尺寸/线宽以设计令牌统一（禁止硬编码颜色，颜色走 CSS 变量/主题令牌）。
- 自定义品牌图形（如耳机产品渲染图）作为资源单独管理，不算图标库。

## Consequences
正面：
- 图标风格与实现统一，消除混用不一致。
- 依赖锁定清晰，便于设计-前端对齐。

负面：
- 个别特殊语义图标可能缺失，需用组合或自定义 SVG 补足（须登记到自定义资源目录，不新增库）。
